# Stale Tabs Cleaner

Short description (<=132 chars):
Automatically find stale browser tabs, close clutter fast, and track 30-day cleanup stats with local-only storage.

GitHub Pages:
https://zozimustechnologies.github.io/staletabs/

## What This Extension Solves

If you keep many tabs open, it is easy to lose track of what is still relevant. Stale Tabs Cleaner helps you identify old, untouched tabs and clean them safely without losing control.

## Core Value

- Detects stale tabs using a configurable time window (hours or days).
- Shows clear stale indicators so old tabs are easy to spot.
- Notifies only when stale-tab count crosses your threshold.
- Includes bulk close for stale tabs with undo support.
- Provides local-only reporting for cleanup activity over the last 30 days.

## Key Features

- Configurable stale definition.
- Exclusion support for pinned and muted tabs.
- Stale badge/count indicator.
- Popup list with close actions and stale reasons.
- Right-click close-all stale tabs action.
- Global undo stack for recent stale close actions.
- 30-day report with daily trend.
- Live View report with open-time and last-active-age columns.

## Privacy and Data Handling

- Local-only storage.
- No cloud database.
- No remote analytics endpoint.
- No user account required.
